# The Threat Coverage Atlas

A field guide to Microsoft Sentinel detection content, organized by the question a SOC analyst actually asks — not by product name. Covers official Microsoft Content Hub solutions, verified community repos, and where my own ([@homelabber](https://github.com/homelabber)) Copilot-assisted builds fill genuine gaps instead of duplicating existing coverage.

**Live site:** https://homelabber.github.io/threat-detection-catalog/
